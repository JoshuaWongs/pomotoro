# AGENTS.md

Notes for an AI coding agent working in this repository. Humans want
[README.md](README.md); this file is the build and test detail that would
clutter it.

## What this is

A desktop Pomodoro timer for Windows. A pixel Totoro sits in the bottom-right
corner of the screen with a clock face on his belly. Standard library only.

## Setup

There is no setup. No dependencies, no virtualenv, no build step, nothing to
install.

- **Windows only.** Transparency, window layering, sound and the single-copy
  check are all Win32. It will not run on macOS or Linux, and making it do so
  is a rewrite, not a patch.
- **Python 3.9 or newer**, with `tkinter`. The Windows installer from
  python.org includes tkinter by default.

```
python pomodoro.py
```

The `X` button on his left flank closes him, in any state except the finish.
He has no frame or taskbar button, so that is the only way out short of ending
the process. Right-click is deliberately **not** bound: it fired on the press,
so the release reached the window underneath and opened the desktop's context
menu. Do not re-add it.

### Command line

| Flag | What it does |
|---|---|
| *(none)* | Run him. If a copy is already running, bring that one to the front and exit. |
| `--force` | Start anyway, even with a copy already running. Useful for testing; two of them in the same corner share one `state.json`, so do not leave it that way. |
| `--make-icon` | Regenerate `totoro.ico` from the sprite and print the path. |
| `--selftest` | Run the fast checks and exit. |

Note what the bare command does **not** do: it writes no shortcut, no registry
key and no Startup entry. On a normal run the only file it creates is
`state.json` beside the code, plus the sound files in a private temp
directory. Keep it that way.

## Tests

Both should pass before and after any change.

```
python pomodoro.py --selftest
python test_timer.py
```

`--selftest` is fast and covers the timer maths, the duration parser, the log
format, the bitmap font, the sprite geometry, the icon container, sound
synthesis, and that the widget builds at all. A missing colour or a typo in the
drawing code is invisible to every other check and only shows up on launch,
which is why the last thing it does is construct the real widget.

`test_timer.py` has 21 sections and feeds clicks at real on-screen coordinates
through the click handler.
It opens windows while it runs. It reports `FAILURES: 0` on success — check
for that line, because an import-time crash can otherwise look like a pass.

### On a machine with no sound card

Playback is asserted by default, because a swallowed audio failure once left
the beeps silent for days without any test noticing. CI runners have no audio
device and cannot answer the question either way, so there:

```
POMODORO_SKIP_AUDIO_CHECK=1 python pomodoro.py --selftest
```

The waveform maths is still checked; only the call into the sound card is
skipped.

`test_timer.py` is deliberately **not** run in CI. It opens real windows and
waits out real animations, and on a shared runner that flakes. The beep spacing
used to be measured here against the wall clock for the same reason; it is now
a property of one waveform and is checked exactly in `--selftest`.

## Before you change anything

Read [DESIGN.md](DESIGN.md), especially **Traps found the hard way**. Several
parts look wrong and are not. The ones that bite hardest:

- The progress slice is a **polygon, not a pie arc**. Tk paints an arc thinner
  than about a degree as a completely filled circle, which made a 50 minute
  timer flash solid at the start. Do not "simplify" it back to `create_arc`.
- `tick()` cancels the tick already queued before scheduling the next, so
  exactly one is ever pending. Calling it directly without that -- which is how
  the tests step the clock -- leaves a second self-renewing chain behind, and at
  33 ms a few hundred of those starve the event loop.
- `ctypes.WinDLL` needs `use_last_error=True` or `get_last_error()` always
  returns zero and the duplicate-copy check silently reports "no other copy".
- Animations carry a **sequence number** and stop if it changes. Without it,
  queued frames keep firing after a button press and park him off-centre.
- The countdown uses `math.ceil`. Flooring made a 50 minute timer read 49:59
  the instant it started.
- The finish shiver is offset **up and left only**, never centred on his mark.
  He rests with his own edges on the window's, so a symmetric shake puts half
  of every offset outside the window, clipped against an invisible edge.
- The beep is measured, not chosen: an 880 Hz square wave, peaking 7 ms in and
  down to a tenth by 90 ms, every 500 ms. Two attempts to improve it by ear
  both landed nearly two octaves too high. Measure before changing it.
- The alarm is **one buffer** `SHOWER_MS` long, not a beep per `PlaySound`.
  Windows opens the audio device on the first play of a run, which made the
  first beep audibly late and the next ones uneven however well the schedule
  was kept. Do not put the thread back.
- The clock face, the slice and every letter are canvas items of their own, not
  part of the sprite image. Anything that moves him has to go through
  `rest_at()`, which shifts the `him` tag and `cx`/`cy` by the same delta.
  Placing `self.body` directly leaves his belly behind and leaves the stored
  offset lying, so the next shiver moves his face by the wrong amount.

## Conventions

- Standard library only. Do not add a dependency.
- Comments explain *why*, not *what*. Match that.
- Non-obvious behaviour gets a check in `--selftest` or `test_timer.py`.

## Do not

- Do not create shortcuts, Startup-folder entries or registry keys unless the
  user asks. The repository deliberately installs nothing; that is a stated
  property of the project.
- Do not turn on session logging. `LOG_SESSIONS` ships as `None` on purpose and
  `--selftest` asserts it.
- Do not commit `state.json`. It is local runtime state and is gitignored.
